# SoftGripLab

面向可变形物体的材料辨识、抓取力规划与冲击扰动分析。

项目主线是：通过接触识别材料 → 根据材料选择夹持量 → 检查扰动下的摩擦承载能力和变形。
现有求解器、优化器和可视化工具负责底层计算，本库负责连接这些工具并提供可复现任务。

## 当前已实现

- **辨识**：基于 SciPy 的标准线性固体模型，联合拟合多组按压—保持数据；支持 CSV，输出参数、残差、条件数和局部不确定性。
- **抓取分析**：固定闭合量、理想恒力控制、依据辨识结果确定闭合量三种策略，评价两侧摩擦承载能力及压缩应变。
- **扰动扫描**：扫描给定半正弦基座加速度脉冲的幅值，输出所需压缩量及是否超过应变限制。
- **三维算例**：直接调用已有 JAX-MPM 的 Neo-Hookean 材料、接触边界和 VTK 导出，完成夹紧、重力加载和基座脉冲扰动；提供无摩擦对照。

一维黏弹性辨识与三维弹性算例目前是两个模型层次，尚未实现同一个黏弹性材料在三维抓取中的闭环。
所有演示数据均为合成或仿真数据，不代表真实机器人验证。当前的“冲击”是指定基座加速度，尚未计算局部撞击物与夹爪的碰撞。

## 快速运行

Python 3.11 以上即可运行参考基准：

```bash
python -m pip install '.[test]'
python -m softgriplab demo --output outputs/demo
python -m pytest -q
```

查看 `outputs/demo/benchmark.png` 和 `report.json`。输入 CSV 的格式、参数含义和三维环境安装见 [英文说明](README.md)。

已有 JAX-MPM 环境时，可以直接从本仓库目录调用该环境的 Python，不必重复安装，也不需要复制求解器源代码。
